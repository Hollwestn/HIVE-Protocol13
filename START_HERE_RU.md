# HIVE: PROTOCOL 13 — быстрый запуск

**0.7.0, публичная техническая альфа.** Основная линия содержит шесть глав. Полный исходный объём ещё не принят; точные ограничения: [docs/STATUS.md](docs/STATUS.md).

1. Установите Setup.exe или распакуйте Portable.zip целиком. Запускайте HIVE-Protocol13.exe вместе с папками app и runtime. Java отдельно не нужна.
2. В разных сетях сначала подключитесь к одной сети Radmin VPN.
3. Хост: «Начать кампанию», выбрать персонажа, адрес 0.0.0.0, TCP-порт 27713, при желании пароль, затем «Открыть лобби».
4. Хост копирует приглашение из лобби и передаёт другу свой IP общей LAN/VPN-сети, порт и отдельно пароль. Другу не подходят 0.0.0.0 и 127.0.0.1.
5. Друг: «Подключиться к хосту», выбрать другую роль, ввести данные. Хост выставляет число участников 2 или 3. Все нажимают «Готов», хост запускает кампанию.

Игра вдвоём не требует третьего искусственного клиента: свободный герой остаётся в капсуле. Всем нужна одинаковая версия, протокол 5.

ЛКМ двигает героя, ПКМ по значку предмета открывает операции с ценой, длительностью и причиной запрета. Shift + ЛКМ — бег; Ctrl + ЛКМ — скрытно; пробел — отмена. На голосовании мир остановлен.

**Выход:** открыть дверь, подготовить шахту и эвакуироваться — отдельные действия. Каждый живой герой выбирает личный выход через ПКМ по объекту. После итогов каждый подтверждает переход в следующую главу.

Нажмите **«Руководство» в главном меню**: откроется офлайн-гайд с картинками, пошаговым прохождением и PDF. В исходниках: [docs/guide/index.html](docs/guide/index.html). Есть сюжетные спойлеры.

K — оружие и сдерживание, I — инвентарь, J — документы, H — история последствий, V — голосование, P — личные разрешения, E — терминал Эхо. PgUp/PgDown только переключают обзор этажа; перемещаются по лестнице.

Сохранения и сетевые идентификаторы находятся у хоста в `%LOCALAPPDATA%\HIVE13`. При обрыве друг возвращается к тому же хосту тем же персонажем; не удаляйте сохранённый идентификатор. Для продолжения хост выбирает прежнее сохранение и свою прежнюю роль. Не публикуйте `.auth` и `settings.properties`.

Проверки: [docs/QA_0_7_0_RU.md](docs/QA_0_7_0_RU.md). Сборка: [BUILD_WINDOWS.md](BUILD_WINDOWS.md).
