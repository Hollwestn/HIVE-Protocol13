## HIVE: PROTOCOL 13 — публичная альфа 0.7.0

Шесть глав кооперативной истории для 2–3 игроков. Минутные фазы, отдельные голоса, физические операции на 2D-карте и существа, которых можно только задержать.

### В этой поставке

- Новое мрачное меню, собственная эмблема приложения и портреты трёх персонажей.
- Исправлены размеры текста и отображение цветов состояния в интерфейсе.
- Хост видит адреса подключения в лобби и может скопировать приглашение для друга. Пароль передаётся отдельно.
- Иллюстрированное русское руководство на 18 страниц: подключение, ПКМ-взаимодействия, выход из главы, этажи, Эхо и условия всех финалов. Офлайн-версия открывается кнопкой «Руководство» в меню.
- Сохранены сетевые исправления протокола 5: сжатие состояния, замена устаревших кадров, независимая отправка подтверждений и команды без блокировки интерфейса.

### Что скачать

- **HIVE-Protocol13-Setup.exe** — обычный установщик Windows x64.
- **HIVE-Protocol13-Setup.msi** — альтернативный пакет Windows Installer.
- **HIVE-Protocol13-Portable.zip** — распаковать целиком, запустить HIVE-Protocol13.exe.
- **HIVE_Protocol13_Guide_RU.pdf** — руководство с изображениями и сюжетными спойлерами.
- **SHA256SUMS.txt** и **RELEASE_MANIFEST.json** — контрольные суммы и состав поставки.

Java включена. Все игроки должны поставить одинаковую версию. Играйте через общую LAN или Radmin VPN; по умолчанию TCP 27713. Хост передаёт другу свой IP в общей сети и порт, все выбирают разные роли и нажимают «Готов».

### Честный статус

Это техническая альфа. Основная шестиглавная линия проходима; полный объём первоначального задания не принят. Сейчас два поведения существ из восьми; остаются полная библиотека событий, дополнительные социальные ветки, баланс и часть визуальной приёмки. Ускоренное прохождение не подтверждает 6–10 часов кампании. Проверка локальными TCP-клиентами не заменяет игру на трёх физических ПК через VPN.
