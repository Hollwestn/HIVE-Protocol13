# LAN и Radmin VPN

Игра использует обычный TCP, без API Radmin, аккаунта игры и внешнего сервера. Прямое подключение из интернета и проброс порта маршрутизатора для VPN не нужны.

1. Все участники устанавливают Radmin VPN с [официального сайта](https://www.radmin-vpn.com/ru/).
2. Один создаёт закрытую сеть с именем и паролем; двое присоединяются к ней. Доступ к сети передавайте друзьям самостоятельно.
3. У хоста в Radmin VPN отображается его IP. Именно этот адрес вводят клиенты. Локальный адрес `127.0.0.1` на чужом компьютере не указывает на хоста.
4. Хост в HIVE выбирает интерфейс `0.0.0.0` (все локальные интерфейсы), порт 27713 либо другой свободный TCP-порт и пароль сессии по желанию.
5. В брандмауэре Windows разрешите входящие TCP-соединения на выбранный порт для доверенной VPN-сети. Не выключайте брандмауэр целиком. Установщик сам не создаёт скрытых правил.
6. На клиенте проверка: `Test-NetConnection IP_ХОСТА -Port 27713`. `TcpTestSucceeded: True` подтверждает достижимость порта, но ещё не совместимость игрового протокола.
7. Подключитесь в игре, выберите разные роли, подтвердите готовность. Остальное — START_HERE_RU.md.

Если порт недоступен: хост должен уже открыть лобби; проверьте совпадение порта, IP интерфейса VPN и правило firewall. Если TCP доступен, но игра отклоняет: проверьте пароль, версию протокола, свободный слот и сохранённый reconnect token. Сеть передаёт прикладной JSON без TLS; пароль игры предназначен для ограничения случайных подключений в доверенной сети, не является шифрованием.

**Статус QA:** локальные TCP-клиенты проверены. Испытание на трёх физических компьютерах через Radmin ещё не выполнено. Этот документ — инструкция для такого испытания, а не утверждение о его прохождении.
