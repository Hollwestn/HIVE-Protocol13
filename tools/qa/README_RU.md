# Проверка медленного подключения

`NetworkSoak.java` запускает настоящий сервер и два либо три NetworkClient. Разведчик подключён через локальный TCP-прокси с ограничением скорости и однократной паузой чтения. Остальные игроки подключаются напрямую. Проверяются сохранение связи, получение состояний и подтверждение каждой команды; на голосовании клиенты выбирают отсрочку. Исходный файл сохранения только читается, тестовый сервер не записывает его и не использует сетевые токены прежней сессии.

Из корня проекта после `mvnw verify` (Java 25):

```powershell
$qaCp='game-client/target/classes;game-server/target/classes;shared-model/target/classes;game-client/target/lib/*'
& "$env:JAVA_HOME/bin/javac.exe" -cp $qaCp tools/qa/NetworkSoak.java
& "$env:JAVA_HOME/bin/java.exe" '-Dhive.dataDir=artifacts/network-soak/data' -cp ("tools/qa;"+$qaCp) NetworkSoak artifacts/copy-of-campaign.json artifacts/network-soak-result.json 180 2 65536 10
```

Аргументы: копия сохранения, файл результата, длительность в секундах, число клиентов (2/3), скорость разведчика в байтах/с, длительность паузы. Родительские каталоги результата должны существовать. Используйте игровые сохранения без файла `.auth`. Тест фиксирует хостом медика; для пары используются медик и разведчик. Для проверки большой истории использовалось состояние шестой главы, 3 клиента и 32768 байт/с. Это проверка сети, а не прохождение сюжета или физического VPN.

Контрольная старая версия, исходные и окончательные отчёты 0.6.1 находятся в `artifacts/alpha061-network`. Предупреждения EOF после завершения ранних версий сценария связаны с закрытием тестового прокси; итоговая связь и подтверждения фиксируются до этого закрытия.

## Проверка окна и команд Эхо

`EchoProbe.java` поднимает настоящий сервер из копии сохранения второй главы с потерянными телами и показывает обычный HudView. В сохранении хост должен быть Эхо, Сигма V5 — запитана и доступна в зоне единственного живого героя. Такой файл получен неудачным прохождением: `artifacts/alpha062/baseline-full3/campaign.json`.

```powershell
& "$env:JAVA_HOME/bin/javac.exe" -cp $qaCp tools/qa/EchoProbe.java
& "$env:JAVA_HOME/bin/java.exe" --enable-native-access=ALL-UNNAMED '-Dhive.mute=true' -cp ("tools/qa;"+$qaCp) EchoProbe artifacts/alpha062/baseline-full3/campaign.json artifacts/echo-probe
```

Три клиента получают собственные сессии. Команды камеры, общей отметки, громкоговорителя и обычного шлюза проходят через TCP; повтор камеры отправляется с тем же commandId. Проверяются цена, физическое состояние двери, настоящий шум, доставка отметки каждому клиенту, истечение данных и сохранение потери тела. Сохраняются снимки окна, команды, результат и отдельное контрольное сохранение. Скрипт не выдаёт ресурсы и не переносит тела; он не является полным прохождением истории. Проверки поставки запускались также со встроенным runtime и JAR Windows-приложения.
